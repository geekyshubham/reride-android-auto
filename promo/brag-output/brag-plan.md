# Brag plan: ReRide

## Rubric
1. Agent-guided reuse toolkit for old Android motorcycle head units.
2. Strongest claim: the hardware is already yours; start with apps, not a universal ROM.
3. Visual hook: a recognizable portrait phone leaves a drawer and becomes a landscape instrument.
4. Actual product material: managed RideHomeView controls, Brand profile fields and the CLI intake.
5. Shortest satisfying film:24s, four scenes.
6. Polished; a practical second-life product film, no startup hype.
7. Original low-key synth bed and two soft interaction cues. No narration requested.
8. Share copy: Give your old Android a second ride. ReRide starts with your phone model, your bike and the maps you need.
9. Flow: phone/bike intake → branded head-unit UI → AA or downloaded-map navigation choice.

## Visual identity
Ground #e8ede4 and #101612; accent #d7ff62; text #101612/#f4f6ee.
Inter900 display and Inter400 body. Phone occupies more than40% of each product shot.
The managed UI is a source-based illustration, labelled as a candidate; no generic device testing is invented.

## Storyboard —24 seconds total
-0–4.5s Problem. “A good phone. Stuck in a drawer.” A portrait phone rests in a visible drawer. Title lands by0.6s and holds3.4s. A short horizontal drawer movement leads into the reuse reveal.
-4.5–11.5s Solution. “Meet ReRide.” Actual intake labels Phone/Bike/Maps arrive at5.0,5.9,6.8s and hold. Recreate RideHomeView's landscape wordmark, Connect wirelessly/Offline maps and radio/sleep controls. Caption: managed UI candidate. A deliberate interaction changes the navigation choice at8.7s.
-11.5–18s Use. “Ride connected. Or ride offline.” One readable AA/local-map choice, one diagrammatic downloaded route with GPS marker. Caption: compatible navigator + downloaded maps required. Text holds more than5s. No actual geographic map or Google UI is fabricated.
-18–24s Why now. “The hardware is already yours.” ReRide name and “App-first. Model-specific firmware.” Finish with the repository name. Brand/payoff holds more than3s.
